# ApiClient.DrawDebugSphere method

Use this function to draw a location in 3D space. Useful for debugging collisisons, and location based events. Based on static internal Unreal method, DrawDebugSphere is not intended for production use.

```csharp
public void DrawDebugSphere(Vector3 location, Color color, double radius = 100m, int segments = 12, 
    double duration = 20m, int lineThickness = 20)
```

| parameter | description |
| --- | --- |
| location | The location in 3D space to draw the sphere. |
| color | The color of the sphere to draw. |
| radius | The radius of the sphere to draw. |
| segments | The number of segments to draw the sphere with. |
| duration | The duration in seconds to draw the sphere. |
| lineThickness | The thickness of the lines to draw the sphere with. |
